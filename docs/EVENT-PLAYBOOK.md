## Choose the problem after inspecting the APIs

Write: “For [specific user], help [specific task] so that [observable benefit].”

Compare candidate ideas by real user value, meaningful contribution from all three APIs, feasibility in the time available, quality of available data, resilience, and demo clarity. These are preparation criteria, not a claim about the event's judging rubric.

For each chosen API explain why removing it makes the solution less useful. Avoid three unrelated widgets or API calls added only to meet the count.

## Build in this order

1. Validate one real request from each chosen API.
2. Normalize outputs and decide parallel versus dependent calls.
3. Implement a complete input → three API contributions → useful user result flow.
4. Test invalid input, slow/failed providers, empty results, quotas and mobile layout.
5. Rehearse a short demo: problem, result, why the three APIs matter, limitations.
