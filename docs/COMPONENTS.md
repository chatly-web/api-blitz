# Civic UI components

The current React components live in `components/`: Avatar, CloudImage, BeforeAfter, MapView, LocationPicker, PhotoUpload, ReportForm, VoteButtons, CommentThread, AdminActions, AppShell and ReportDetail. Accessible Button/Input/Textarea/Badge primitives live in `components/ui/`. See DESIGN.md for the white/green design system and docs/SETUP.md for provider configuration.
