# API Blitz

A simple, responsive website starter using HTML, CSS, and JavaScript.

## Project structure

```text
api-blitz/
├── index.html
├── assets/
│   ├── styles.css
│   └── app.js
├── package.json
├── vercel.json
└── README.md
```

## Run locally

Install Node.js, then run `npm start` and open http://localhost:3000.
No dependencies or build step are required.

## Deploy

Push this folder to a GitHub repository named `api-blitz`, then import that repository into Vercel. Select the Other framework preset, leave the build command empty, and use the repository root as the output directory.

## Customize

Edit page content in `index.html`, styling in `assets/styles.css`, and interactive behavior in `assets/app.js`.

The demo uses local sample data. It does not send requests to an external API or require API keys.
