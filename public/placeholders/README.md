# Category sample photos

These photographs are downloaded from Wikimedia Commons. They are generic category previews, never citizen evidence. Source pages, author credit, license and modifications for each file are recorded in `lib/category-placeholders.json` and displayed at `/photo-credits`.

Files are resized/re-encoded as WebP. The UI crops and slightly blurs them. Each photo retains its original license, including attribution/share-alike requirements where applicable. Do not apply the project's code license to these photos. The original source page links provide the complete license information.
